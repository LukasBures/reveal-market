# Contracts

Foundry workspaces for on-chain components.

**Workspaces**
- `contracts/zen` core RevealMarket contracts.
- `contracts/polygon` auxiliary contracts.

**Commands**
- `contracts/run_local.sh` runs both workspaces.
- `contracts/run_tests.sh` runs tests for both.

**Testing**
- `forge build` and `forge test` in each workspace.
